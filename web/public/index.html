Insert adds the snippet at your cursor in the code, or at the end of main if you have not clicked into the code yet. It stays highlighted so you can see it.

    Reading the chart

    • Text: written out as it is.
    • Reference: inserts the branch of that name. The dashed line leads to it.
    • Choice: the alternatives stacked between two rails. One of them is picked each time.
    • Empty alternative: picking it leaves the choice out, so the choice is optional.
    • Range: one alternative per value in the range.
    • Tag and guard: an alternative with a tag sets it; an alternative with a guard is only available when the tag is set.
    • Repeat, transform, any order: chips on top of the part they change.
